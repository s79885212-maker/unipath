# Working on UniPath (for AI coding agents)

Read this before changing anything. It applies to every agent (Codex, Claude Code, others).

## Talking to the owner
- The owner writes in English or Russian; **answer in Russian**.
- Commits show the owner alone: **no `Co-Authored-By` lines**, no agent attribution.

## Branches, test copy and releases
| Branch | Address | What it is |
|---|---|---|
| `dev` | https://s79885212-maker.github.io/unipath/staging/ | test copy — **all work goes here** |
| `main` | https://s79885212-maker.github.io/unipath/ | public site — **only on a release the owner asks for** ("заливай") |

- Commit to `dev` and push `origin dev`. The "Staging check" workflow runs the tests; if they pass, "Deploy to GitHub Pages" rebuilds both copies.
- Release (only when the owner says so): `git checkout main && git merge --ff-only dev && git push origin main && git checkout dev`.
- Never push to `main` otherwise. Never force-push. Stage files explicitly (no `git add -A`).
- Do not commit these local files: `data/universities.us2 2.js`, `scratchpad_photos_new.json`, `scratchpad_photos_us200.json`, `assets/img/universities/wheaton-college-massachusetts/`. No file names with spaces in the repo (`git ls-files | grep -c " "` must be 0).
- Several agents share this one folder and the one branch `dev` (one test copy). To avoid overwriting each other:
  - before starting, run `git status` and `git pull --rebase origin dev`; if there are uncommitted changes you did not make, do not touch or revert them — ask the owner;
  - keep changes small and commit + push each finished step right away (do not leave work uncommitted);
  - before pushing, `git pull --rebase origin dev`, rerun the tests, then push; if the rebase conflicts, stop and tell the owner;
  - the cache-buster `?v=NN` is shared: take the next number after the one currently in `index.html` on `dev`.

## Before every commit
1. `node tests/run.js` — all tests pass (the run prints `N passed, 0 failed`).
2. Bump the cache-buster in `index.html` (`?v=NN` → `?v=NN+1`, every occurrence).
3. Add a short entry (in Russian) to `AUDIT_EXPANSION_PROGRESS.md`.
4. Check the change on the test copy after the push (Russian version `?lang=ru`, phone width 360 px, no console errors; `?i18n=collect&lang=ru` lists untranslated strings in `I18N.missing`, a Set).

## Data rules (the site's whole value is that the data is true)
- **Never invent data.** Official university pages only; aggregators and search summaries are leads to verify on the official page, never sources.
- Every dated or priced fact keeps its source URL and the day it was read (`source`, `verified`).
- A field the pages do not state stays `null` and shows as "not checked". Write what is unconfirmed into `verification.unconfirmed`.
- Do not compute averages from ranges, do not carry last year's dates forward (mark them `previous-cycle`), do not call a sum of lines the university's total, keep per-semester figures per semester (a yearly figure must say "calculated by UniPath").
- Every university with a confirmed yearly cost gets an `annualCost` entry in `data/match.js`.
- New English strings need Russian translations in `data/i18n/ru.js` (the Python builders register them with `L(en, ru)` from `tools/us200_std.py` and write them with `flush()`).
- `data/i18n/ru.js` is the only dictionary to edit (English text → Russian). The published copy is generated by `tools/i18n_pack.js` (called from `build-artifact.py`): keys become fingerprints and long one-country texts go to `ru.<country>.js`, loaded on demand. Never edit the packed files; a test checks the packed dictionary translates exactly like the source.
- JSON-format record files (`data/universities.ca.js`, `data/universities.us3.js`) are edited with `tools/ca50_gaps.py` (`load(path)` / `save(...)` keep the layout); see `tools/ca50_gaps1.py`…`ca50_gaps5.py` and `tools/fix_v134.py` for examples.

## What an agent must not do
- No downloads of files (PDFs, images, archives) without the owner's explicit permission for those files. Campus photos come only from Wikimedia Commons under free licences, with author and licence shown.
- Do not bypass CAPTCHAs, bot checks ("Just a moment…"), geo-blocks or "Access denied" pages — mark the item unconfirmed instead.
- Do not submit forms with personal data; calculators may be used only to read published figures.
- Do not log in to services for the owner, make purchases, or change repository or hosting settings.


## Разрешение владельца на фотографии — 1 ноября 2026
Владелец явно разрешил скачивать и добавлять свободно лицензированные фотографии Wikimedia Commons для всех университетских профилей и попросил учитывать разрешение в дальнейшей работе. Повторное разрешение на каждый такой снимок не требуется. Конкретное текущее задание USA50 Completion ограничено существующими 50 IDs: разрешены кандидаты из манифеста, проверенные замены и Wabash. Кампус/объект, автор, лицензия, условия, фактическое изображение и атрибуция всё равно проверяются перед установкой. Это исключение не разрешает скачивать произвольные PDF/архивы/платные изображения или добавлять вузы вне задания.

При пересборке прежними tools/us_expansion50_batch*.py завершённые расширения направлений восстанавливаются tools/us50_completion_programmes.py, затем tools/us50_completion_matrix.py и tools/us_expansion50_report.py. Не терять evidence дополнений.

После прежних batch builders также применяйте tools/us50_completion_finance.py и tools/us50_install_photos.py --metadata-only до обновления матрицы/отчёта. Режим --metadata-only восстанавливает проверенные ссылки/кредиты из Git-манифеста и уже установленных assets, проверяя SHA-256; скачивать оригиналы повторно не нужно. Обычный режим installer требует проверенные raw downloads и не обращается к сети. Кандидаты со статусом hold не устанавливаются.

После completion_finance также применяйте tools/us50_remaining_evidence.py: он восстанавливает индивидуально прочитанные оставшиеся стоимости из sources. Не выводит annualCost, не согласует конфликты и не присваивает год недатированной таблице. Новое исследование сохраняет прежние источники и явно ограничивает программу, кампус, период и набор.

После прежних batch builders применяйте также tools/us50_completion_admissions.py. Он восстанавливает вручную описанные документы international first-year и явно доказанную политику экзаменов из структурированных publicAdmissionDocuments/publicTestingPolicy; не выводит пригодность узбекской квалификации, GPA или год дедлайна из примечаний. Старые даты чтения исходных требований сохраняются. Старое основание Fall2026 не заменяет отдельное подтверждение Fall2027.
