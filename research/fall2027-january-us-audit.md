# Аудит сроков США для Fall 2027 — январская партия

Проверено 16 ноября 2026 года. Основа — dev `09365ec73`. Взяты 20 вузов из январской очереди, которые не разбирались в предыдущих ручных волнах. Сверены страницы приёма, финансовых форм и сопроводительных документов. RD — Regular Decision, ED II — Early Decision II. Даты без подтверждённого цикла помечены как общие правила, даты решения отделены от подачи. Час или часовой пояс без подтверждения для конкретного события не показывается.

## Где абитуриент рискует пропустить подачу

- **Cornell** — приоритетный CSS Profile для иностранного первокурсника 2 января 2027, в день подачи заявки. 19 января относится к общим сопроводительным материалам; у отдельных программ есть собственные сроки портфолио.
- **Lehigh** — международная инструкция даёт 15 января для CSS Profile и при ED II, и при RD. Общая таблица помощи 2027/28 для ED II даёт 1 января. Обе ссылки показаны в карточке; применимый срок CSS Profile для ED II оставлен неподтверждённым.
- **Dartmouth** — официальные страницы называют и 1, и 2 января. Цикл и более поздняя дата не подтверждены. **Northwestern** — датированный календарь указывает 1 февраля для помощи, недатированная международная инструкция — 2 февраля.
- **Tufts и Vassar** — запрос помощи отмечается в самой заявке на поступление. Срок CSS Profile может наступить позже, однако это не переносит срок указания запроса. У Tufts предупреждение видно прямо в строках ED II и RD; сроки школьных и налоговых документов показаны отдельно.
- **Bowdoin** — семь дней отсчитываются от предложения о зачислении для иностранцев, кроме граждан Канады. **Princeton** — форма PFAA нужна отдельно, CSS Profile не используется.
